🛡️

Instalando no Windows com segurança

O BrasilCord ainda pode exibir avisos do Windows porque o instalador não possui assinatura digital reconhecida. Um certificado de assinatura de código pode custar cerca de € 300 por ano, dependendo do fornecedor e das condições; esse é um valor estimado, não uma taxa fixa nem garantia de aprovação automática pelo SmartScreen.

Baixe somente pelo GitHub oficial, confira o nome do arquivo e mantenha o antivírus ativo. Não é necessário executar como administrador por padrão. Se o instalador solicitar elevação, confira a origem e o motivo antes de autorizar. Não ignore avisos de segurança se não tiver certeza da procedência.

Instalador distribuído pelo repositório oficial. Pode aparecer um aviso do Windows se o instalador ainda não tiver assinatura digital. O app web usa internet e alguns recursos dependem do navegador.

DÚVIDAS FREQUENTES

Perguntas e respostas.

Preciso executar como administrador para instalar no Windows?+

Não por padrão. Execute o instalador obtido no GitHub oficial normalmente. Se ele solicitar autorização de administrador, verifique a procedência e a justificativa. Um aviso de aplicativo desconhecido não é resolvido simplesmente executando como administrador.

Como posso apoiar o BrasilCord?+

Você pode acessar a área de apoio e seguir para a página de contribuições na loja RedeArk. O apoio é voluntário e não afeta o acesso à conta BrasilCord.

O BrasilCord funciona no celular?+

Sim! A versão web adaptada ao celular pode ser acessada em BrasilCord Mobile. Você também pode usar a opção Adicionar à tela inicial no navegador compatível. Alguns recursos variam conforme o dispositivo.

Preciso de uma conta?+

Sim. Para usar as comunidades e mensagens próprias do BrasilCord, é necessário cadastrar uma conta e entrar nela.

Onde encontro as novas versões?+

Os instaladores são publicados no GitHub Releases oficial. O aplicativo também conta com um mecanismo de atualização.

As chamadas e o compartilhamento de tela estão disponíveis?+

A versão desktop inclui recursos de câmera e compartilhamento de tela diretamente nas calls. A disponibilidade e a qualidade podem variar conforme rede, permissões e dispositivo.

A verificação por código de e-mail já está funcionando?+

O recurso de código de seis dígitos foi preparado no sistema, mas depende da configuração do serviço de envio de e-mails e pode ainda não estar ativo.
